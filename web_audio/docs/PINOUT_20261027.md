# PetLink 引脚映射（权威版，2026-10-27）

> 本文数字取自**已编译固件的 `sdkconfig`**（`build/petlink_monitor/sdkconfig`）与 `main/Kconfig.projbuild` 默认值，
> 并与 `audio_i2s.c` / `voice.c` / `result_display.c` / `rtc_ds3231.c` / `tjc_display.c` 的实际调用逐一对照。
> 板子：**ESP32-S3-N8R2**（8MB Flash / 2MB PSRAM，板载 CH343 USB 串口）。

---

## 0. 只接 OLED + 麦克风 + 串口屏（精简版）

| INMP441 麦克风 | 接到 | 备注 |
|---|---|---|
| VDD | **3V3** | 不要接 5V |
| GND | GND | — |
| SCK（BCLK） | **GPIO4** | 时钟，单向 |
| WS（LRCLK） | **GPIO5** | 帧同步，单向 |
| SD（DATA） | **GPIO6** | 数据，麦克风 → 板 |
| L/R | **GND** | **必须接 GND**（选左声道），接 3V3 会读到静音 |

| SSD1306 OLED | 接到 | 备注 |
|---|---|---|
| VCC | **3V3** | — |
| GND | GND | — |
| SDA | **GPIO8** | 与 RTC 共用（本项目不接 RTC 时独占） |
| SCL | **GPIO9** | 100 kHz，地址 **0x3C** |

| TJC 串口屏 | 接到 | 备注 |
|---|---|---|
| 5V | **5V**（建议独立供电） | 背光电流大，别从板子 3V3 取 |
| GND | **GND（必须共地）** | 满屏 0x00 的第一嫌疑 |
| 屏 RX | **GPIO18** | 板 TX → 屏 RX，**交叉** |
| 屏 TX | **GPIO21** | 屏 TX → 板 RX，**交叉** |
| — | — | 波特率 **9600**，`bauds` 掉电保存 |

**只接这三个时的行为变化**（都是预期，不是故障）：

| 现象 | 原因 |
|---|---|
| 串口 `MONITOR rtc=absent`，屏/OLED 时间是 `--:--` | 没接 DS3231，`epoch=0`；识别与显示正常 |
| 记录里时间戳全是 0 | 同上，蓝牙记录的时间字段无意义 |
| 关于不上功放 | `VOICE_ENABLED` 编进去也不会报错（I2S TX 无回读），只是没声音 |
| `CONFIG_PETLINK_TJC_ENABLED` 必须为 `y` | 否则屏驱动不编入，屏永远黑（见 §5） |

## 2. 总线与电气参数

### 2.1 I2C（OLED + RTC 共用一条）

| 项 | 值 |
|---|---|
| 控制器 | `I2C_NUM_0`（`result_display.c:44`） |
| 引脚 | SDA=GPIO8，SCL=GPIO9 |
| 速率 | 100 kHz（`scl_speed_hz=100000`，OLED 与 DS3231 都是） |
| OLED 7 位地址 | **0x3C**（`CONFIG_PETLINK_OLED_ADDRESS`，启动时 `i2c_master_probe` 探测，不在就 `fatal("ERR OLED")`） |
| DS3231 7 位地址 | **0x68**（`rtc_ds3231.c:3`，`#define DS3231_ADDR 0x68`） |
| 上拉 | 依赖模块自带（常见 ZS-042、0.96" OLED 模块都带 4.7k–10k）。**两个模块并联后不要再各加一组，避免等效上拉过强** |

⚠️ **OLED 是硬依赖**：`pl_display_init()` 失败直接 `fatal`，整机停在 `ERR OLED`。RTC 不在只降级（`rtc=absent`，蓝牙仍可用但 epoch=0）。

### 2.2 I2S 麦克风（I2S_NUM_0，RX）

| 项 | 值 |
|---|---|
| 采样率 | 16 kHz（`audio_i2s.c:21`） |
| 位宽 | 32-bit slot，24-bit 数据**高位对齐**（`CONFIG_PETLINK_I2S_HIGH_ALIGNED=y`） |
| 声道 | `I2S_SLOT_MODE_STEREO`，但**代码只取每帧第一个 slot**（`slots[2*i]`，`audio_i2s.c:47`） |
| 因此 | **INMP441 的 L/R 必须接 GND（选左声道）**。接 3V3 会一直读到静音，表现为"能录到全 0" |

INMP441 供电：VDD→**3V3**、GND→GND。不要接 5V。

### 2.3 I2S 扬声器（I2S_NUM_1，TX）

| 项 | 值 |
|---|---|
| 采样率 | 16 kHz（`voice.c:32`） |
| 位宽/声道 | 16-bit、Stereo（单声道数据**复制到左右两个 slot**，`voice.c` 里 `stereo[2k]=stereo[2k+1]=samples[i]`） |
| GAIN 脚 | 悬空 = 9 dB |
| SD 脚 | 接 3V3 使能；拉低静音 |

MAX98357A 供电：VIN→**5V**（走 VIN/VOUSB，别走 3V3，功率不够会破音/复位）。喇叭接 OUT+/OUT−，**不要接 GND**（BTL 输出）。

### 2.4 TJC 串口屏（UART1）

| 项 | 值 |
|---|---|
| 引脚 | ESP32 **GPIO18 = TX** → 屏 **RX**；ESP32 **GPIO21 = RX** ← 屏 **TX**（交叉，不是同名对接） |
| 波特率 | **9600**（`CONFIG_PETLINK_TJC_BAUD`；注意屏侧 `bauds` 是掉电保存的，改过一次就一直生效） |
| 协议 | TJC/Nextion 指令集，帧尾 `FF FF FF` |
| 供电 | 屏 **5V 独立供电**，**必须与 ESP32 共地**——"收不到应答、满屏 0x00"第一嫌疑就是没共地 |
| 开关 | `CONFIG_PETLINK_TJC_ENABLED=y` 才编入；关掉时这两个脚空闲 |

### 2.5 控制台串口（UART0）

GPIO43(TX)/44(RX) 是 ESP32-S3 的 UART0 默认脚，板上经 CH343 转 USB。固件在 UART0 上跑 115200 的命令行（`r/c/d/f/s/h`），烧录也走这条。

## 3. 电源分配

| 供电 | 供给 |
|---|---|
| **5V**（VIN / VOUSB） | MAX98357A VIN、TJC 屏（建议独立 5V，屏背光电流大） |
| **3V3** | INMP441 VDD、SSD1306 VCC、DS3231 VCC、MAX98357A SD |
| **GND** | 全部共地，包括 TJC 屏和功放 |

DS3231 模块带充电电路，配 **LIR2032 可充纽扣电池**，不要用普通 CR2032（会充爆）。

## 4. 不能用的引脚（S3 硬约束）

| GPIO | 为什么不能用 |
|---|---|
| **19 / 20** | USB D− / D+（原生 USB） |
| **26 – 32** | SPI0/SPI1，接内置 Flash 与 PSRAM（N8R2 这两颗都在模组内，脚不外露） |
| **0** | Strapping（BOOT），上电电平决定启动模式 |
| **3** | Strapping（JTAG 信号源） |
| **45** | Strapping（VDD_SPI 电压） |
| **46** | Strapping（ROM 打印/启动），且只能输入 |
| **43 / 44** | UART0 控制台 + 烧录（改了就失联） |
| 33–37 | N8R2 是四线 PSRAM，理论可用；但多数 S3 开发板没引出，**用前先看板子丝印** |

当前固件**一个保留脚都没占用**，全在 4/5/6/8/9/15/16/17/18/21。

## 5. 改引脚的唯一正确姿势

引脚全部走 Kconfig，**不要改 .c 文件里的宏**：

1. `main/Kconfig.projbuild` 里改 `default`（或 `idf.py menuconfig` → PetLink application / PetLink TJC screen）。
2. 要固化进构建，把值写进 `sdkconfig.monitor.defaults`，例如 `CONFIG_PETLINK_SDA_GPIO=10`。
3. 重新 `idf.py build`。
4. **改 I2C / TJC 脚之后要重跑一次外围自检**——OLED 探测失败会直接 `fatal`，屏改错只是没反应（不会崩）。

`main/CMakeLists.txt` 不需要动，引脚不是编译期常量文件。

## 6. 接错症状对照表

| 症状 | 最可能的原因 |
|---|---|
| 串口 `FATAL ERR OLED`，一直重启 | SDA/SCL 接反、OLED 地址不是 0x3C（有的模块 0x3D）、没共地 |
| 串口 `MONITOR rtc=ok` 但时间不走 | DS3231 电池没装/装反，或 SDA/SCL 虚接（OLED 能亮说明总线通，但 RTC 芯片没响应） |
| 识别结果恒为同一类、`nonzero=0`、`peak=0` | INMP441 的 L/R 接了 3V3（应接 GND），或 SD/SCK 接反 |
| 有声音但破音/重启 | 功放 VIN 接了 3V3（要 5V）；SD 脚悬空（要拉 3V3） |
| 屏无任何反应，串口却正常 | GPIO18/21 没交叉（TX 对 TX）、屏没共地、屏侧 bauds 被改过 |
| 屏偶尔闪乱码 | 只共了信号没共地，或屏与板子分开供电但地线太长 |
| 烧录失败 `Failed to connect` | 用了 GPIO43/44 之外的口，或板子没进下载模式（按住 BOOT 再上电） |

## 8. 外挂蓝牙模块（可选，**多数情况不需要**）

### 8.1 先分清：ESP32-S3 已经内置 BLE 5.0

| 需求 | 需要外挂模块吗 |
|---|---|
| 手机连板子、收识别结果、下发命令 | **不需要**。现役固件已有 BLE 广播 `PetLink-Monitor` + 服务 `504c…0001`（TIME/CURSOR/REC/**CTRL/STATUS**），安卓与 iOS 都能连 |
| 手机当串口终端（GATT 收发） | **不需要**。`CTRL`（0005）+ `REC`（0004）就是现成的双向通道 |
| BLE HID（当遥控器/键盘）、iBeacon | **不需要**，S3 内置 BLE 就能做 |
| 经典蓝牙 **SPP** 串口（老式 HC-05 生态） | 需要外挂。S3 **不支持 BR/EDR** |
| 经典蓝牙 **A2DP**（手机放歌给板子播） | 需要外挂，或换经典蓝牙主控（S3 做不到） |

**结论：只想"连手机"，一根线都不用加。** 外挂模块的唯一正当理由是"必须用经典蓝牙"，代价是安卓-only（iOS 不做 SPP）、多 20–40 mA 功耗、2.4G 与 BLE 互相干扰、固件多一套 UART 协议要维护。

### 8.2 如果确定要挂：用 UART2，引脚如下

资源占用现状：UART0 = 控制台（43/44）、UART1 = TJC 屏（18/21），**UART2 空闲**。

| 外挂模块（HC-05 / HC-06 / JDY-31 等 SPP 模块） | 接到 | 说明 |
|---|---|---|
| VCC | **5V**（带 LDO 的模块）/ **3V3**（裸模块） | 看模块丝印，别想当然 |
| GND | GND | 必须共地 |
| TXD | **GPIO11** | 模块 TX → 板 RX（UART2 RX） |
| RXD | **GPIO10** | 板 TX → 模块 RX（UART2 TX），必要时分压 |
| STATE | **GPIO12**（可选） | 连接状态指示：已连=高电平，可做"手机在连"检测 |
| EN / KEY | **GPIO13**（可选） | 拉高进 AT 模式，用于改波特率/名称 |

这几个脚（10/11/12/13）当前**全部空闲**，不与麦克风、I2C、功放、屏冲突。

### 8.3 接线注意

1. **电平**：HC-05/HC-06 的 TXD 输出 3.3V，可直连 ESP32；RXD 输入多数模块也是 3.3V 兼容。若模块标 5V 逻辑，RXD 必须分压（1k/2k）。
2. **波特率**：SPP 模块默认多为 9600，与 TJC 屏同值但**互不影响**（不同 UART）。改模块波特率要走 AT 模式，别在数据模式下发 AT。
3. **干扰**：外挂模块与 S3 的 BLE 都在 2.4G，贴太近会互相降速。模块天线离板载天线至少 2 cm。
4. **固件侧要写的东西**：`uart_driver_install(UART_NUM_2, ...)` + 一套行协议解析 + 与 BLE `CTRL` 命令的语义对齐，**否则等于挂了个没人用的串口**。
5. 不接这个模块时，10/11/12/13 保持悬空即可，固件不会去碰。
